## Rules

1. `profile/README.md` is generated by `scripts/repo_index.py`. Never edit it by
   hand: change the script, run it, commit both.
2. Everything here is public. No private repository name, no secret, no path of
   Romain's machines beyond what the inventory already states.
3. The workflow commits as `github-actions[bot]`; a human commit carries Romain's
   identity. No co-author line, no assistant mention.
4. Creating, renaming, archiving or changing the visibility of a repository is
   written in the vault inventory in the same gesture; the index only reflects it.
